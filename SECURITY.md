# Security policy

## Reporting a vulnerability

Please report a vulnerability **privately**, and do not open a public issue for it. Use the "Report a vulnerability" button
of the Security tab of this repository (GitHub private vulnerability reporting).

Please include the version of the agent, what you did, what you expected and what happened. We acknowledge a report within
five working days, and tell you when it is fixed.

## What is in scope

- The agent program and the `Teeckbox.Outbound` library of this repository.
- In particular: a way to make the agent reach a destination outside its allow list, to read or write a credential it
  holds, to open a port, or to run a command.

Teeckbox, the server, is reported by email to the address on [teeckbox.com](https://teeckbox.com).

## Supported versions

The latest release of the agent, and the previous minor version.
